# Лабораторна робота 6 — Пагінація, тести, документація

## Реалізовано
Нескінченне прокручування з послідовними сторінками, блокуванням паралельних запитів і перевіркою кінця. Jest покриває мапінг, синхронізацію/помилки, пагінацію, чергу watchlist, ViewModel та обчислення рейтингу.

## Файли для звіту
`mobile/src/data/repository/MovieRepository.ts`, `mobile/src/viewmodels/usePopularMoviesViewModel.ts`, `mobile/__tests__/*`, `README.md`.

1. Footer-індикатор наступної сторінки. 2. Успішний результат `npm test`. 3. Архітектурна Mermaid-діаграма.
