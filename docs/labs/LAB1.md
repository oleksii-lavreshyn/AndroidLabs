# Лабораторна робота 1 — Основи та UI

## Реалізовано
Екран входу з локальним станом привітання, поле пошуку з фільтрацією та 20 реалістичних мок-фільмів. Компоненти мають український текст, доступні мітки й адаптивну світлу/темну тему.

## Файли для звіту
`mobile/src/app/login.tsx`, `mobile/src/app/(tabs)/index.tsx`, `mobile/src/mocks/movies.ts`, `mobile/src/theme/theme.ts`, `Rules.md`.

## Знімки екрана
1. Вхід до натискання кнопки. 2. Привітання після входу. 3. Сітка популярних фільмів. 4. Відфільтрований пошук.
