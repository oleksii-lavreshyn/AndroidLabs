# Лабораторна робота 2 — Типобезпечна навігація

## Реалізовано
Expo Router із `typedRoutes`, параметрами `username` і `movieId`, переходами `slide_from_right`/`fade`. Об’єкт `MovieSelection` серіалізується у JSON та безпечно перевіряється під час парсингу.

## Файли для звіту
`mobile/app.json`, `mobile/src/navigation/routes.ts`, `mobile/src/app/_layout.tsx`, `mobile/src/app/(tabs)/_layout.tsx`, `mobile/src/app/movie/[movieId].tsx`.

## Знімки екрана
1. Перехід Вхід → Популярні з ім’ям. 2. Перехід картка → Деталі. 3. Нижня навігація.
