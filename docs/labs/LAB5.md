# Лабораторна робота 5 — Фонові задачі та сповіщення

## Реалізовано
`CHECK_NEW_RELEASES` отримує now-playing, порівнює ID у SQLite та надсилає локальне сповіщення. Налаштовано Android-канал і дозвіл. Натискання сповіщення відкриває деталі у foreground/background/cold start. Ручний запуск використовує ту саму функцію.

## Файли для звіту
`mobile/src/utils/backgroundTasks.ts`, `mobile/src/utils/notificationHandler.ts`, `mobile/app.json`, `mobile/src/app/(tabs)/settings.tsx`.

## Знімки екрана
1. Дозвіл сповіщень. 2. Ручна перевірка. 3. Сповіщення. 4. Відкриті з нього деталі.
